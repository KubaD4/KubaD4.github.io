DEEP LEARNING / MULTIMODAL RETRIEVAL
  1. 01Encode the reference photoFrozen CLIP ViT-B/32 maps the face to a unit vector z in a 512-d space.
  2. 02Add signed text edits−Smiling, +Eyeglasses, +Wearing_Hat become text embeddings that keep their sign.
  3. 03Compose the queryA learned network predicts Δz. The query q = normalize(z + Δz) travels across the sphere.
  4. 04Search 19,962 facesCosine similarity to q ranks the whole CelebA test gallery; the closest 500 go forward.
  5. 05Rerank, return the top 10A calibrated attribute reranker orders the pool. Existing photos are retrieved, never generated.

Schematic 3D view of the 512-d CLIP space. Source, query and the ten faces are the final system's actual output for query 12.

MAIN IDEA

Search an image gallery using a reference photo and requested attribute changes, while preserving the parts that should stay the same.

MY CONTRIBUTION

Built a hybrid retrieval system on frozen CLIP image/text embeddings. Trained a source-conditioned composition model and a calibrated attribute reranker, and evaluated alternatives using cached embeddings and Slurm GPU jobs.

CHALLENGE

Applying several edits without losing the reference context. Plain embedding addition is a starting point; learned composition and candidate verification improve control.
